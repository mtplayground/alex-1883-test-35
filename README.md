# Suanpan

A browser-based suanpan abacus built with Vite, React, and TypeScript.

## Development

```bash
npm ci
npm run dev
```

The development server listens on `0.0.0.0:8080`.

## Production Build

```bash
npm run build
```

The static production bundle is generated in `dist/`. See
[docs/deployment.md](docs/deployment.md) for self-hosted deployment steps.
